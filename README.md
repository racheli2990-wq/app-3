# NOVA PLAYER

נגן וידאו ומוזיקה לאנדרואיד עם ממשק עברי כהה, בחירת קבצים מקומית, כתוביות SRT/VTT חיצוניות, שליטה במהירות ובדילוגים.

## Build
`gradle assembleDebug`

ה-APK נבנה אוטומטית ב-GitHub Actions ונשמר כ-artifact וכקובץ Release.

## Offline
האפליקציה אינה מבקשת הרשאת INTERNET. פתיחת המדיה והכתוביות נעשית דרך בורר הקבצים של Android.

## Local model
מסך ההגדרות מאפשר לבחור ולשמור קובץ מודל מקומי. בשלב זה נשמרת בחירת הקובץ בלבד; מנוע זיהוי דיבור (ASR) והרצת תמלול בפועל אינם מחוברים עדיין. כדי לספק כתוביות אוטומטיות אמיתיות נדרש לשלב מנוע ASR תואם Android ואת פורמט המודל המתאים.
