# LifeVault – הכספת האישית שלך

> Build pipeline enabled: every update to `main` creates an installable Android APK.

אפליקציית Android מקומית בעברית: פתקים, משימות, כספת מסמכים ועוזר AI.

## תכונות
- לוח בית עם סיכום פתקים, משימות וקבצים.
- פתקים עם עריכה, חיפוש והקלטת קול.
- משימות עם תיאור, יעד וסימון השלמה.
- כספת קבצים: ייבוא מסמכים ותמונות והעתקתם לאחסון הפרטי של האפליקציה.
- עוזר מובנה עם חיפוש וסיכום גם ללא מודל.
- מנוע שפה מקומי LiteRT-LM עם ייבוא קובץ מודל תואם `.litertlm`.
- אין הרשאת INTERNET במניפסט.

## AI מקומי
העוזר פועל בשני מצבים: כלים מובנים שעובדים מיד (חיפוש וסיכום פשוט) ומודל שפה אמיתי שפועל על המכשיר לאחר ייבוא מודל .litertlm. המודל אינו כלול ב-APK כי הוא גדול בהרבה מהאפליקציה. מודל התחלתי אפשרי הוא Qwen3-0.6B בפורמט LiteRT-LM. ביצועים תלויים בזיכרון ובחומרת המכשיר.

## פרטיות
פתקים, משימות וקבצים נשמרים באחסון הפרטי של האפליקציה. אין סנכרון רשת, גיבוי אוטומטי או תמלול דיבור בגרסה זו. הסרת האפליקציה או ניקוי הנתונים עלולים למחוק מידע.

## Build
דרישות: JDK 17, Android SDK Platform 36, Gradle 9.5.0.

```bash
gradle --no-daemon assembleDebug
```


Build configuration updated to use AGP built-in Kotlin support.
